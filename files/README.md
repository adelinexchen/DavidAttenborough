## Welcome to My Home Page (Gallery)

The home page of my website, often referred to as the Gallery page, offers a captivating visual experience. Let me walk you through some key features and considerations:

### JavaScript Execution and DOM Loading
I was told by my tutors to include following code snippet:
```javascript
document.readyState == 'complete' || document.readyState == 'interactive'
```
however did not include it as some of my Javascript needs to be executed before the DOM elements load, and I have placed my script tags in the appropriate position so it loads when I want it to.

### Reset Button for User Convenience
Located prominently at the very bottom of the home page, you'll find a large, eye-catching red reset There is a large red reset button located at the very bottom of my home page. This is not only for the sake of my demo, but also allows the users to reset their progress if they wish to restart. This is done by basically clearing the user’s local storage.

### Optimized Mobile Mode
My mobile mode works on both Safari and Chrome, but it should ideally be run on Chrome as Chrome has a smaller minimum window width, which I have accounted for.
